## 🚀 Featured Projects

### [PDF Research Paper Chatbot with RAG](https://github.com/prishaakumar/pdf-researchpaper-bot)
- AI chatbot using **HuggingFace embeddings** and **FAISS vector search** to answer questions about uploaded academic PDFs.
- Powered by **OpenRouter API (GPT-4o)** for context-aware responses, built with **Python Flask**.

### [Explain It All LLM](https://github.com/prishaakumar/explain-it-all-llm)
- **Streamlit** web app generating AI-powered explanations at three difficulty levels using **OpenRouter API**.
- Integrated **Google Custom Search API** for comprehensive responses and deployed on Streamlit Cloud.

### [Spotify Wrapped But Better](https://github.com/prishaakumar/spotify-wrapped-but-better)
- Full-stack dashboard with **React.js, Material-UI, and Flask**.
- Implemented ML-powered sentiment analysis using **TextBlob** and an AI-driven recommendation engine.
